## Fokkus IDE 1.3.2 — Pull Requests en Source Control

### Corregido
- **Sección PULL REQUESTS en Source Control:** ahora aparece de verdad junto a Changes y Graph. El hotfix de 1.3.1 no lo resolvía: buscaba el contenedor de Source Control antes de que Theia lo creara, así que la sección nunca se agregaba. Además, en layouts ya guardados Theia oculta las secciones nuevas. Ahora la sección se registra con el mecanismo oficial de Theia (`onWillCreateWidget`, el mismo que usan los plugins de VS Code) antes de restaurar el layout, y se muestra automáticamente la primera vez. Si después la ocultas, esa decisión se respeta.

### Nuevo
- **Vista global de PRs:** sin filtro, la sección muestra todos los Pull Requests abiertos de todos tus repositorios (hasta 100 repos), ordenados por última actualización y con el nombre del repo en cada tarjeta.
- **Filtro por repositorio:** selector con "Todos los repositorios" y tus repos de GitHub. Con un repo elegido se habilita el filtro de estado (Abiertos / Cerrados / Todos). El botón "Detectar" selecciona el repo de la carpeta abierta. El filtro se recuerda por workspace.
- **Búsqueda local** por repositorio, número o título.

### Cambiado
- **"Pedir revisión a agentes"** (antes "Revisar con IA"): los agentes del IDE revisan el PR y dan feedback (hallazgos por severidad, riesgos y recomendaciones) **sin aprobarlo ni rechazarlo**, sin comentar en GitHub y sin modificar archivos. El prompt obtiene el diff desde el repositorio del PR, así que también funciona con PRs de repos distintos al workspace.

### Versionado
- Todos los paquetes (lerna, aplicaciones y extensiones) pasan a 1.3.2.
