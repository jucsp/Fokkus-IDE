## Fokkus IDE 1.7.1 — Bandeja Pre-Kanban: Slack con sesión web y Gmail con credenciales JSON

### Nuevo
- **Slack en modo sesión web (`xoxc-` + cookie `d`)** (#26): puedes conectar el Slack corporativo a la Bandeja sin crear una App de Slack ni pedir permisos de administrador del workspace. Fokkus usa tus permisos de usuario y sigue sin escribir nunca en Slack.
  - El campo de token acepta `xoxb-`, `xoxp-` y ahora también `xoxc-`.
  - Nuevo campo **Cookie d (`xoxd-`)**. Es obligatorio con un token `xoxc-`: el campo se resalta y muestra cómo copiar la cookie `d` de slack.com desde las herramientas de desarrollador del navegador (Aplicación › Cookies).
  - Badge **«Sesión Web» / «Bot Token»** en el panel «Fuentes y conexiones», según el tipo de credencial guardada.
  - La cookie se guarda cifrada en el almacén del sistema operativo (cuenta `slack.cookie_d` del servicio `fokkus-ide.triage`). Las peticiones a la API de Slack la envían como `Cookie: d=…`.
  - También se leen las variables de entorno `SLACK_MCP_XOXC_TOKEN`, `SLACK_COOKIE_D` y `SLACK_MCP_XOXD_COOKIE`, compatibles con la configuración del MCP de Slack.
  - Validaciones: un token `xoxc-` sin cookie `d` se rechaza con un error claro. Si guardas un token bot o de usuario, se borra la cookie `d`. «Eliminar» borra el token y la cookie.
- **Gmail / Google Workspace con credenciales JSON** (#26): nuevo interruptor **«Pegar credenciales JSON (client_secret.json)»** para no copiar a mano el Client ID y el Client Secret.
  - Acepta el `client_secret.json` de Google Cloud Console (`installed` o `web`), el formato plano `{ client_id, client_secret, refresh_token }` y el JSON de clientes MCP que guardan el `refresh_token` en la raíz junto a `installed`/`web`.
  - Si el JSON no es válido o no trae `client_id`, verás un mensaje de error claro.
  - Los campos escritos a mano tienen prioridad sobre los valores del JSON.

### Limitaciones conocidas
- Un `client_secret.json` descargado de Google Cloud Console **no trae refresh token**. Mientras el IDE no tenga un flujo OAuth propio, hay que pegar el refresh token en su campo, que sigue visible con el modo JSON activo. Si el JSON trae `refresh_token` (por ejemplo, el de un cliente MCP), la configuración queda completa.
- El token `xoxc-` y la cookie `d` caducan cuando cierras la sesión de Slack en el navegador. Si pasa eso, vuelve a copiarlos.
